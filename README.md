### 🚀 Projetos

**🔧 [PiBarber](https://pibarber.app)** · sistema de agendamento e gestão para barbearias, **em uso por 2 barbearias**. Criado com um sócio.
- Cliente agenda pelo celular; o dono gerencia agenda, caixa, comissões e relatórios
- Três perfis de acesso (dono, assistente e cliente), com as permissões controladas no próprio banco de dados
- Regra no PostgreSQL que impede dois agendamentos no mesmo horário
- E-mails automáticos e testes end-to-end com Playwright
- **Stack:** Next.js · TypeScript · Supabase (PostgreSQL) · Vercel

**✅ [TaskFlow](https://github.com/DEVpazoti/taskflow)** · API REST de tarefas, em desenvolvimento, construída do zero etapa por etapa.
- Node.js, Express e TypeScript, com respostas e erros em JSON
- Configuração por variáveis de ambiente, build para produção, Prettier e Conventional Commits
- **Próximos passos:** PostgreSQL com Prisma, login com JWT, testes automatizados e front-end em React

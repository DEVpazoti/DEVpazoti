### 🚀 Projetos

**🔧 [PiBarber](https://github.com/DEVpazoti/pibarber)** · [pibarber.app](https://pibarber.app)
Sistema de agendamento e gestão para barbearias, **em uso por 2 barbearias reais**. Criado com [Rafael Vetrano Cairo](https://www.linkedin.com/in/rafael-vetrano-cairo-37a833232/).
- Três perfis de acesso (dono, assistente e cliente), com as permissões aplicadas no próprio banco (Row Level Security no PostgreSQL)
- Constraint no banco que impede dois agendamentos no mesmo horário, mesmo com pedidos simultâneos
- Agenda, caixa, comissões, relatórios e e-mails automáticos
- Stack: Next.js, TypeScript, Supabase (PostgreSQL), Vercel, testes end-to-end com Playwright

**✅ [TaskFlow](https://github.com/DEVpazoti/taskflow)** · em desenvolvimento
API REST de gerenciamento de tarefas, construída do zero e etapa por etapa, para aprender cada decisão.
- Node.js, Express e TypeScript, com build para produção e configuração por variáveis de ambiente
- Respostas e erros em JSON, código padronizado com Prettier e commits no padrão Conventional Commits
- Próximos passos: PostgreSQL com Prisma, login com JWT, testes automatizados e front-end em React

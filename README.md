**`Estudante de Engenharia da Computação · Desenvolvimento de Software`**

### 🚀 Projetos

**🔧 [PiBarber](https://pibarber.app)** · sistema web de gestão para barbearias, **em uso por 2 barbearias**. Criado com um sócio.
- Cliente agenda pelo celular; o dono controla agendamentos, comissões, financeiro e relatórios
- Três tipos de usuário (dono, assistente e cliente), cada um com acesso só ao que precisa
- **Stack:** Next.js · TypeScript · Supabase (PostgreSQL) · Vercel

**✅ [TaskFlow](https://github.com/DEVpazoti/taskflow)** · API REST de gerenciamento de tarefas, em desenvolvimento, construída do zero.
- Node.js, Express e TypeScript, com rotas em JSON e tratamento de rotas inexistentes (404)
- Variáveis de ambiente, build para produção, Prettier e Conventional Commits
- **Próximos passos:** PostgreSQL com Prisma, login com JWT, testes automatizados e front-end em React

**🗺️ RoadMap Unaerp** · aplicação web com mapa interativo do campus para orientar calouros, apresentada em palestra no Desafio da Engenharia da Computação.

**🚦 Semáforo Inteligente** · TCC na Etec (2021): protótipo com Arduino UNO que, via radar, calcula a velocidade do carro e abre o próximo semáforo antes de ele chegar (onda verde).
